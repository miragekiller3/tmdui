  1. 自动生成工程及代码
    1. 打开编辑器，创建一个window。菜单->文件->另存为，指定一个资源文件名，资源文件名就是工程名
    2. 如果想工作在vc下，则保存成rc，如果想工作在Qt下，则保存成qrc
    3. 在编辑器中选中当前编辑的对话框，选择右键属性，打开后有3个功能：
      4. 1：为这个对话框指定名字
      2：为对话框生成代码
      3：生成工程文件，此工程文件可以直接被vc或Qt Creator打开
    4. 编辑器打开的rc可以另存为qrc，打开的qrc也可以另存为rc。但是要注意另存后会冲掉文件中的非DUI信息。

  2. 类型及文件命名规范
    1. "Native"结尾的类型，表示这是一个native的类型，可以与平台函数交互。例：TMFloatNative、TMHWndNative、CRectNative
    2. "TM"结尾的类型，或不以"Natvie"结尾的类型，表示平台无关，保证跨平台，但是不保证能与平台函数交互。例：TMFloat、TMHWnd、CRect、CWindowTM
    3. 有些类之所以使用"TM"结尾，是因为这些类名已经被平台占用。比如"CWindow"已经被TML占用，所以只能用"CWindowTM"。
    4. 源码文件名以"tm"开头的，表示这个文件跨平台。
